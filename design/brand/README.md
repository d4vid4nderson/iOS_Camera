# Brand

| File | Use |
|---|---|
| `mark-M.png` | The **M** mark. Not used on the shutter or app icon (too close to the engraved logo on a well-known camera's shutter); kept for reference |
| `wordmark-M36.png` | The **M36** wordmark: App Store page, launch screen, large spaces |

Both are white on transparent; tint as needed (UI copper: sRGB 0.92 / 0.45 / 0.13).

**Construction.** The M is the uppercase M from *Kodchasan SemiBold*. The 3 in the
wordmark is the same M turned 90° clockwise, its stroke re-thickened to match after
scaling. The 6 is drawn in the same construction (flat bars, round ends, the 3's bowl
radius) rather than taken from the font. Generator: see the design notes in PR #11.

in the app; the font file itself is not bundled.
